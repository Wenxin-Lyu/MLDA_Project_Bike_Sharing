# How to Use This Repository (Beginner Git/GitHub Guide)

This guide will help you download (clone), edit, and contribute to this project, even if you are new to Git and GitHub.

---

## 1. Prerequisites

- **Git** must be installed on your computer.  
  Download: https://git-scm.com/downloads
- **GitHub account** (free): https://github.com

---

## 2. Download (Clone) the Repository

Open your terminal (Command Prompt, PowerShell, or Git Bash) and run:

```bash
git clone https://github.com/ChristianKuckelkorn/MLDA_Project_Bike_Sharing.git
```

This will create a folder named `MLDA_Project_Bike_Sharing` with all project files.

---

## 3. Change into the Project Directory

```bash
cd MLDA_Project_Bike_Sharing
```

---

## 4. Create Your Own Branch (Recommended for Contributions)

```bash
git checkout -b my_feature_branch
```
Replace `my_feature_branch` with your own branch name.

---

## 5. Make Changes

- Open and edit files as needed (for example, with VS Code or Jupyter Notebook).

---

## 6. Save and Commit Your Changes

```bash
git add .
git commit -m "Describe your changes here"
```

---

## 7. Push Your Changes to GitHub

```bash
git push -u origin my_feature_branch
```

---

## 8. Create a Pull Request

1. Go to your repository on GitHub.
2. You will see a prompt to "Compare & pull request" for your branch.
3. Click it, add a description, and submit the pull request.

---

## 9. Update Your Local Repository

To get the latest changes from the main repository:

```bash
git checkout main
git pull origin main
```
